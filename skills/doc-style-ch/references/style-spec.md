# doc-style-CH 视觉规范

## 设计目标

形成适合中文研究报告、项目方案、长篇说明和文学文档的稳定视觉身份：温润、克制、清晰，有纸墨气息，但不仿古、不牺牲现代可读性。

## 颜色

- `paper-0`：主纸色，暖白。
- `paper-1`：次级纸色，用于页面背景和表头。
- `ink-0`：深墨正文。
- `ink-1`：次级正文与说明。
- `ink-2`：元信息、编号和弱提示。
- `cinnabar`：朱砂强调色，用于章节标记、链接和关键边线。
- `cinnabar-soft`：浅朱砂，用于深墨背景上的辅助标签。
- `moss`：苔绿色，仅用于成功、已确认或积极状态。
- `warning`：偏暗赭朱色，仅用于警告提示的边线。

不要再引入蓝紫品牌色或大面积渐变。危险提示使用偏暗朱红，不使用荧光红。

## 字体

- 大标题、章节标题：`Kaiti SC`、`STKaiti`，回退到 serif。
- 正文、引用、表格：`Songti SC`、`STSong`、`Noto Serif CJK SC`。
- 标签、元信息、代码外界面：`PingFang SC`、`Hiragino Sans GB`。
- 代码：`SFMono-Regular`、`Consolas`、monospace。

正文推荐 `1.04rem`、行高 `1.95`；正文最大行宽约 `46rem`。

## 信息层级

1. Kicker：短、稀疏字距、朱砂浅色或墨灰。
2. 文档标题：楷体，大字号，最多两行。
3. 副标题：宋体，说明文档价值和范围。
4. 元信息：短标签，不写成长段。
5. 章节：编号与标题并列，章节间保留明显呼吸。
6. 正文：自然文流优先，辅助块次之。

## 布局

- 桌面端：`18rem` 左侧深墨导航栏；正文居中，最大宽度约 `78rem`。
- 正文内容列最大 `48rem`，表格和代码可扩展到章节宽度。
- 移动端：侧栏改为顶部标题区，目录横向滚动；正文左右边距至少 `1rem`。
- 打印：去除固定定位、纸张纹理和交互提示；目录与正文保持可读。

## 内容块

- 引言：朱砂左边线，字体略大。
- 引用：浅纸色背景，保留出处。
- 提示框：左边线区分 note、warning、success，不使用圆角卡片墙。
- 表格：细线、浅色表头、移动端允许横向滚动。
- 代码：深墨底、暖白字；只用于真正的代码或命令。
- 图片：限制宽度，提供说明文字；不强制裁切。

## 禁止项

- 盲测导航、A/B 候选、胜者、可用度、评分进度和答案键指纹。
- 玻璃拟态、霓虹、渐变按钮、浮夸投影和通用后台仪表盘风。
- 每节一张独立卡片造成的碎片化。
- 为“古典感”堆叠花纹、印章、龙凤、卷轴或难读文言。
