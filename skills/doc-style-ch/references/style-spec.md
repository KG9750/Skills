# doc-style-CH 视觉规范

## 设计目标

形成适合中文研究报告、项目方案、长篇说明和图片摘要的稳定视觉身份：温润、克制、清晰，有纸墨气息，但不仿古、不牺牲现代可读性。HTML、PDF 和 PNG 必须看起来属于同一系统，不得为不同格式另起一套品牌。

## 颜色

- `paper-0`：主纸色，暖白。
- `paper-1`：次级纸色，用于页面背景和表头。
- `ink-0`：深墨正文。
- `ink-1`：次级正文与说明。
- `ink-2`：元信息、编号和弱提示。
- `cinnabar`：朱砂强调色，用于章节标记、链接和关键边线。
- `cinnabar-soft`：浅朱砂，用于深墨背景上的辅助标签。
- `moss`：苔绿色，仅用于成功、已确认或积极状态。
- `warning`：偏暗赭朱色，仅用于警告提示的边线。

不要再引入蓝紫品牌色或大面积渐变。危险提示使用偏暗朱红，不使用荧光红。

## 字体

- 大标题、章节标题：`Kaiti SC`、`STKaiti`，回退到 serif。
- 正文、引用、表格：`Songti SC`、`STSong`、`Noto Serif CJK SC`。
- 标签、元信息、代码外界面：`PingFang SC`、`Hiragino Sans GB`。
- 代码：`SFMono-Regular`、`Consolas`、monospace。

主标题、章节标题和章节数字使用约 `600` 的字重，明显高于正文；不可只放大字号而保持与正文相同的视觉重量。

正文推荐 `1.04rem`、行高 `1.95`；阅读列从常规窗口约 `48rem` 起随视口增长，超宽屏上限约 `76rem`。

## 信息层级

1. Kicker：短、稀疏字距、朱砂浅色或墨灰。
2. 文档标题：楷体，大字号，最多两行。
3. 副标题：宋体，说明文档价值和范围。
4. 元信息：短标签，不写成长段。
5. 章节：编号与标题并列，章节间保留明显呼吸。
6. 正文：自然文流优先，辅助块次之。

## 布局

- HTML：正文单列居中，页面容器上限约 `92rem`；边距、标题字号、章节间距和内容宽度使用 `clamp()` 随窗口流式变化，不设置页面级固定最小宽度。
- 正文内容列在宽屏上随视口从约 `48rem` 增长至 `76rem`，表格和代码在章节宽度内自适应；不得继续固定在窄列。
- HTML 导航：左上角固定深墨目录按钮；鼠标 hover、点击和键盘均可展开仅含目录结构的面板。面板背景使用 60% 深墨透明度和轻度背景模糊，不重复标题、副标题或元信息；触控目标至少 `44px`，面板不得超出视口并允许内部滚动。
- 标题区：主标题下不额外输出 `doc-style-CH` 品牌署名，只保留内容所需的副标题和元信息；元信息 tag 每项只使用一层单线框，不叠加内外双框。
- 移动端：保持单列正文和完整目录能力；表格、代码块在自身容器内滚动，不让整个页面横向滚动。
- PDF：A4 纵向，去除固定定位、纸张纹理、目录按钮和交互目录；主标题使用约 `33pt` 的醒目字号并优先保持自然单行，不允许末尾孤字换行；每页底部居中显示“当前页 / 总页数”。
- PNG：摘要默认 1600 × 2000 画布，深墨顶栏加单列摘要区，不显示交互目录；大标题优先自然单行，正文接近有效画布宽度。用户明确要求完整单张长图时，复用完整内容源并按实测内容高度扩展画布，最高不超过 8192px；不得裁切或盲目缩小字号。

## 内容块

- 引言：朱砂左边线，字体略大。
- 引用：浅纸色背景，保留出处；左右统一占满内容列宽，上下高度随文字自动增长，不设置固定高度；说明正文约为普通正文的 88%–90%，出处再小一级。
- 提示框：左边线区分 note、warning、success，不使用圆角卡片墙；左右统一占满内容列宽，上下高度随文字自动增长，不设置固定高度；说明正文约为普通正文的 88%–90%，标题再小一级。代码区和表头不套用这条说明字号规则。
- 表格：细线、浅色表头、移动端允许横向滚动。
- 代码：使用纸墨编辑器结构，取消最外层框线，以统一浅灰底色和约 `.45rem` 的轻微圆角形成克制层次，避免棕色或深色背景与正文反差过大。工具栏保持透明，不在语言标签所在行添加加深色带。语言统一显示为 `<bash>`、`<zsh>`、`<fish>`、`<python>` 这类尖括号标签，保留明确语言名；朱砂只用于标签文字，不添加胶囊或独立底色，也不用可配置的 shell 提示符代替语言名。HTML 可显示复制按钮，PDF/PNG 隐藏按钮；只用于真正的代码或命令。
- 图片：限制宽度，提供说明文字；不强制裁切。

## 禁止项

- 盲测导航、A/B 候选、胜者、可用度、评分进度和答案键指纹。
- 除目录面板为保证半透明背景可读性而使用的轻度模糊外，不使用玻璃拟态、霓虹、渐变按钮、浮夸投影和通用后台仪表盘风。
- 每节一张独立卡片造成的碎片化。
- 为“古典感”堆叠花纹、印章、龙凤、卷轴或难读文言。
