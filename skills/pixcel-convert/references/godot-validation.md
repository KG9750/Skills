# Godot validation and evidence

## Evidence levels

1. **Source QA**: required project/demo files, PNG dimensions, palette, hard alpha, atlas geometry, SpriteFrames atlas paths/regions/order, TileSet atlas metadata/origin/collision, manifest contracts, and cache hygiene.
2. **Godot import**: a clean `--headless --editor` import creates loadable textures.
3. **Godot resource QA**: Godot loads the TileSet, SpriteFrames, scene, and GDScript; checks every animation name, frame count, FPS, loop flag, sprite offset, collision count, and active playback for multi-frame demo animations.
4. **Resource readback**: Godot reads atlas regions or frame textures and writes an image through CPU `Image` APIs.
5. **GUI runtime screenshot**: a non-headless Viewport is actually rendered and captured.
6. **Human visual approval**: the user accepts the shown output.

Never substitute one level for another.

## Clean verification sequence

Start from a cache-free pack. Source QA rejects pre-existing `.godot/`, `*.import`, and `*.ctex` without deleting them. The `--godot` path then performs the import/resource checks and removes the cache generated by that run whether the engine succeeds or fails. Expected engine failures are reported as `error:` without a Python traceback.

```bash
Godot --headless --editor --path <pack-dir> --quit-after 20
Godot --headless --path <pack-dir> -- --qa
```

If non-headless launch fails, report the failure and continue with source and Headless resource QA. Do not call a Pillow preview or CPU resource readback a GUI screenshot.

After verification, remove generated delivery caches:

- `<pack-dir>/.godot/`
- `*.import`
- `*.ctex`

Keep the source PNG, atlas, `.tres`, `.tscn`, manifest, demo script, verification logs, and any explicitly generated resource-readback preview. Godot 4.4+ may generate a `.gd.uid` sidecar beside each GDScript during import. Treat a valid sidecar as versionable project metadata rather than cache: keep it only when its matching `.gd` exists, and record every retained path in `asset_manifest.json` under `godot_uid_sidecars`, including when a later resource-QA step fails. A source-only build declares an empty list; `verify_pack.py --godot` updates the list after the engine invocation and rejects orphan, malformed, or undeclared sidecars.

## Godot usage

TileMapLayer:

```gdscript
tile_map.tile_set = preload("res://resources/<pack>_tileset.tres")
tile_map.set_cell(cell, 0, atlas_coordinates)
```

AnimatedSprite2D:

```gdscript
sprite.sprite_frames = preload("res://resources/<asset>_sprite_frames.tres")
sprite.animation = &"idle"
sprite.offset = Vector2(sprite_offset_x, sprite_offset_y)
```

Read the generated `asset_manifest.json` for `atlas_coordinates` and `sprite_offset`.
