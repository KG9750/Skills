# Preview Plan

| Order | Asset | Goal | Required content | Output |
| ---: | --- | --- | --- | --- |
| Cover | Cover (not counted) | Win the listing click | Theme, asset type, key spec | 630×500 PNG/GIF |
| 1 | Hero scene | Show game-ready appeal | Actual delivered assets | Unified landscape image |
| 2 | Content overview | Prove total scope | Categories, variants, counts and counting method | Labeled overview |
| 3 | Category / variant matrix | Make contents scannable | Main categories, characters, props or states | Labeled matrix |
| 4 | Motion / states | Prove animation or state quality | True FPS/directions/loops, or states/angles/sizes for static packs | GIF, video cover or comparison |
| 5 | Specification card | Remove import doubt | Grid, canvas, origin, frames, formats | Diagram/card |
| 6 | Detail / variants | Prove consistency | Pixel/material/prop/character close-ups | Labeled close-up |
| 7 | Composed use case | Show modular value | A room, scene, roster or effect combination | In-context image |
| 8 | Workflow / boundaries | Remove final doubt | Layers, slicing, import, license summary or not-included content | Diagram/card |
| 9 | Engine demo (if applicable) | Prove integration | Entry scene, resources, tested version | Runtime/editor image or remove row |
| 10 | Tier comparison (if applicable) | Explain purchase | Free/full or Standard/Source | Comparison card or remove row |

Target: exactly 8–10 distinct primary previews, plus the separately counted cover. Rows 1–8 are mandatory roles; rows 9–10 are conditional. A conditional row may be replaced by a genuinely independent second use case, category breakdown or technical example. Never pad the set with crops, recolors or minor variations of the same image.

If the asset scope cannot honestly support all eight mandatory roles, do not lower the count or manufacture duplicates. Combine it with related assets, add real specification/sample/workflow value, or treat it as an add-on instead of an independent product page.
